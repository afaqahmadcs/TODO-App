Multi-Device Breakpoint Specifications

Desktop (1280px+) desktop_windows

Persistent 256px sidebar command rail, 12-column layout grid, omni-search Cmd+K bar, multi-column task kanban and deep data views.

• Padding: margin-lg (40px)
• Task Row Height: 48px
• Elevation: Ambient Drop Shadow Layer 1-3
Tablet (768px - 1279px) tablet_mac

Collapsible 64px icon-only rail or drawer, 8-column canvas with 2-column flex cards, touch-optimized hit areas (minimum 44x44px).

• Padding: margin-md (24px)
• Gutter: gutter-md (24px)
• Flyout dialogs replace wide side panels
Mobile (<768px) smartphone

Single-column linear task flow, persistent bottom navigation bar, floating action button for instant capture (+), gesture swiping for quick complete.

• Padding: margin (16px)
• Typography: headline-xl-mobile fallback
• Floating Task Capture Button
